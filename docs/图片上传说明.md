# 上传自己的制服款式照片

1. 打开 [餐饮制服页面](http://127.0.0.1:8080/#collection)，登录管理员账号。
2. 找到已有款式，点击“上传款式图片”或“更换图片”。
3. 选择 JPG/JPEG 或 PNG，每张不超过 5 MB，单边不超过 6000 像素，总像素不超过 1200 万。
4. 成功后首页、目录、定制和对应订单缩略图显示照片。未上传或图片失效时使用 SVG 示意。

上传不新增款式，照片是固定外观，改变配色、衣长或刺绣不会自动修改照片，定制参数与报价按表单计算。普通用户只能查看款式照片。

## 保存方式

图片内容保存在 `D:\lsecode\.local\uploads\styles\`，服务器生成随机 `.jpg` 或 `.png` 文件名；已有 MySQL 字段 `shirt_style.image_url` 只保存访问地址，例如 `/uploads/styles/随机编号.png`。更换后旧文件暂时保留。

IDEA 工作目录设为项目根目录，也可用 `UPLOAD_DIRECTORY` 指定绝对位置。迁移时要同时复制数据库和上传文件目录，仅复制 JAR 不包含后来上传的照片。

## 精简后的调用流程

```text
App.vue 选择文件
  → api.ts 发送 FormData，携带 Bearer JWT
  → LoginInterceptor 检查管理员角色
  → CatalogController 接收 MultipartFile
  → CatalogServiceImpl 检查已有款式
  → ImageStorage 验证、重新编码并保存图片
  → ShirtStyleMapper / XML 更新 image_url
  → 返回 ProductView，ProductImage.vue 显示照片
```

上传：`POST /api/admin/styles/{styleCode}/image`，文件字段为 `file`。读取：`GET /uploads/styles/{filename}`。开发时 Vite 代理 `/api` 和 `/uploads` 到 8080；完整 JAR 由 8080 同时提供页面、接口与图片。

汇报时可以说：“管理员选择照片，前端用 FormData 发送，后端用 MultipartFile 接收。拦截器核对管理员身份，图片工具检查并保存文件，MyBatis 更新数据库图片地址，Vue 使用 img 标签显示。”报价和图片已合并在目录业务里，不再单独建图片 Controller 与 Service。
