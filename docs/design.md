# 莱赛尔餐饮制服设计方案

品牌定位：面向咖啡厅、酒店西餐厅、烘焙工坊的餐饮服装定制平台。用户按餐饮岗位选制服，再确认面料、颜色、尺寸和收货信息，管理员推进制作流程。保留数据库中的现有制服款式，不扩展通勤服装品类。

配色：纸白 #F7F8FA、松绿 #204D42、雾绿 #DFEBE4、鸢尾紫 #8978A9、浅紫 #EEEAF4、墨色 #273831。标题使用系统宋体衬线字体，操作和数据使用微软雅黑 / PingFang SC，正文不依赖外部字体服务。

导航：平台首页、餐饮制服、制服定制、面料选配、我的订单；登录后可打开量体档案，管理员可进入工作室管理。首页标题为“为餐饮团队，定制舒适制服。”，款式列表按数据库中的餐饮场景筛选。

布局：桌面侧栏提供核心导航，首页以制服线稿和餐饮团队文案为重点，下方提供现有制服入口。定制页左侧显示服装预览，右侧按设计、尺寸、确认三个步骤组织表单；移动端导航转为顶部横向导航。

```text
┌────────┬────────────────────────────────────┐
│ 品牌   │ 页名                         账户  │
│ 导航   ├────────────────────────────────────┤
│        │ 餐饮制服文案          制服线稿     │
│        ├────────────────────────────────────┤
│        │ 餐饮场景筛选   搜索                │
│        │ 现有制服      现有制服      制服   │
└────────┴────────────────────────────────────┘
```

服装线稿由本地 SVG 绘制，读取款式的领型、袖型，并随配色和定制细节变化。款式、面料和价格通过 MySQL 目录接口读取，选择配色时同时选择对应面料，服务端再次校验。交互提供键盘焦点、加载状态、失败处理、弹窗关闭与焦点恢复。

登录使用 JWT，页面在当前标签页保存 token。登录过期时重新打开登录弹窗，登录后回到正在操作的页面。密码哈希和权限检查在后端完成，管理员的菜单与接口均检查角色。

范围：本机业务演示，包含真实 MySQL 数据读写、订单事务和 JWT 权限校验。付款、短信和物流未接入，生产进度由管理员维护。线稿用于制服轮廓和配色示意，不等同于物理试衣效果。
