# 精简版验收记录

日期：2026-10-13（Asia/Shanghai）。运行环境为 Windows、Java 25.0.3、Node 24.18.0 和本机 Chrome。项目仍以 Java 17 为编译目标。

## 本次精简

核心流程保留为登录、制服选配报价、量体下单和订单进度。技术栈保持 Vue 3、Spring Boot、MyBatis Mapper/XML、MySQL 和 JWT `HandlerInterceptor`。

- 后端主代码由 61 个 Java 文件减少到 52 个，业务集中为账号、目录、订单三个模块。报价和款式图片读写并入目录模块，三个 Service 的实现放在 `service.impl`。
- 去掉收藏、搜索排序、独立面料介绍页、帮助弹窗、草稿缓存、管理员统计和非衬衫预览分支。款式、面料、配色、衣长、刺绣、数量、量体、报价、订单以及管理员上传照片和推进状态保留。
- 主要业务改用普通循环和清楚展开的代码；Mapper/XML、实体、拦截器和工具继续按包分工。
- JWT 撤销记录改为内存保存；每次启动生成新的实例标识，重启后旧 token 失效，需要重新登录。当前密钥从已有本地配置加载。
- 管理员权限依据 Spring 实际匹配到的接口路径和数据库当前角色检查，编码后的 URL 同样需要登录与管理员权限。
